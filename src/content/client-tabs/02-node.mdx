For Node.js, Deno, Bun, and other JavaScript runtimes without a DOM, start with
the [JavaScript client](https://www.npmjs.com/package/@thumbrella/client).
Use its `Client` API when your application needs to control requests, caching,
batching, or streaming directly.

- Runs in Node 18+, Deno, Bun, and modern browsers
- Zero runtime dependencies, only needs `fetch`
- Batched streaming requests with intermediate results
- Optional persistent cached results
- Placeholders for failures, even if disconnected or misconfigured
- Integrates with `sharp` or other image libraries
- Thumbrella server supports 100+ formats

```ts
//  Install with: `npm install @thumbrella/client`  //

import { Client } from "@thumbrella/client";

// Connect to server, defaults to $TBR_CONNECT with no argument.
const tbr = await new Client("http://localhost:3114").verify();

// Stream results as they complete
for await (const result of tbr.stream([
  "https://demo.thumbrella.dev/media/padres-stereo.exr",
  "https://demo.thumbrella.dev/media/golden-gate.exr",
])) {
  console.log(result.url, result.status);
}
```

The source comes with several starting point examples. See the [client
documentation](https://thumbrella.dev/docs/client/) for more details and
information.

- [examples/element.html](https://github.com/thumbrella-dev/clients/blob/main/typescript/examples/element.html)
  Use the `<tbr-thumb>` element in a small, fixed gallery.
- [examples/browser.html](https://github.com/thumbrella-dev/clients/blob/main/typescript/examples/browser.html) 
  Stream multiple thumbnails as they render through the Client API.
