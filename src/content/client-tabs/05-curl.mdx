---
label: Curl
---

The direct HTTP requests are designed to be usable without rich clients. This
can work from any language with any HTTP library. Also from command line tools
like `curl` or `wget`.

- Efficiently processes multiple thumbnails in parallel
- Stream batch results with newline-delimited JSON (`ndjson`)
- Every request results in a valid image or placeholder
- Server provides advanced HTTP caching support
- Thumbrella server supports 100+ formats

```bash
curl -OG "http://localhost:3114/thumb.jpeg" \
  --data-urlencode "url=https://demo.thumbrella.dev/media/harbor-trucks.mp4"
```

To interact with Thumbrella Cloud, register online for a quick and free
account. Then add the token into the Authorization header.

```bash
curl -OG "https://cloud.thumbrella.dev/thumb.jpeg" \
  --data-urlencode "url=https://demo.thumbrella.dev/media/golden-gate.exr" \
  --header "Authorization: Bearer tbr_e_3QnzBcWx7KpRmYT2000example"
```

For most applications, prefer one of the language client libraries. They
provide caching, result handling, and convenient batching or streaming APIs.

See the [HTTP API documentation](https://thumbrella.dev/docs/http-api/) for
batch requests, streaming, authentication, and result formats. See the
[client API documentation](https://thumbrella.dev/docs/client/) for the
higher-level alternatives.
