---
label: Self Host
---

Self hosting your own Thumbrella server is designed to be straightforward
and simple. Find the prepackaged option that best fits your environment.

```sh
# Run and manage binaries through node
npx --yes @thumbrella/server serve

# Docker container
docker run -it --name tbr --publish 3114:3114 --rm thumbrella/server
```

By default the server will listen on port `3114`. This can be override by 
setting `$TBR_PORT` to a different value. There are several other
settings also managed by environment variables. These can be validated
by running `thumbrella check` for a simple report and diagnostics.

Binaries are distributed through 
[Github Releases](github.com/thumbrella-dev/thumbrella/releases/latest). 
The attested archives contain the portable and static executable.

See the [Server Documentation](https://thumbrella.dev/docs/server/) 
for more commands and configurations. The server is also quite simple to
compile for yourself.
