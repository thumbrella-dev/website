## Thumbrella Cloud

The <u>free</u> **Thumbrella Cloud** account is <u>recommend for
most users</u>. This include an amazing worldwide edge cache and supports all
formats and features of the Thumbrella server. No infrastructure to manage or
servers to maintain. The free service provides over 70,000 unique thumbnail 
renders per month.

Prefer unlimited usage or offline capability? Learn about [self-hosting your own
server](server/) which is free, open-source, and fully featured.

Accounts above their [usage limits](/docs/cloud/#limits) can still use the
Thumbrella api for cached and simple results. Complicated renders will fallback
on simpler placeholders in the meantime. The service degrades but contiues to
work reasonably.

Every account can create multiple
[authentication tokens](https://thumbrella.dev/docs/cloud/#auth-tokens) 
and divide up their quota across each of them. Each token gets custom
[restrictions and rules](https://thumbrella.dev/docs/cloud/#token-limitations).

## Free Demo Server

The [Thumbrella Demo Gallery](https://demo.thumbrella.dev) has a collection of
media and acts as a <u>free server</u> for the media it hosts. No account
needed, point any client connect string to `https://demo.thumbrella.dev` and
start making requests.
